# ERA Ecoturismo Rutas y Autotransportes

Sitio web de ERA: tours de ecoturismo y renta de autobuses con chofer.

> **El sitio oficial ahora está en Lovable: https://era-ecoturismo.lovable.app**
> Este repo solo redirige allá y guarda los archivos de marca (`marca/`). La versión HTML original está en el historial de git.

- `index.html`: página principal (HTML, CSS y JS sin dependencias).
- `aviso-privacidad.html`: aviso de privacidad simplificado (plantilla, revisar con el cliente).
- `img/`: logo, íconos e imagen para redes sociales.

## Pendientes del cliente
Los datos que faltan están marcados entre corchetes en rojo en la página:
número de WhatsApp (constante `WHATSAPP` en `index.html`), teléfono, correo,
dirección, horarios, mapa, destinos, fotos de la flota y testimonios reales.

## Publicación
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
